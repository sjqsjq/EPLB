## 4. 完整性观察：boot-draw 非确定性（环境性；封存战役中同样存在；非 rev1 缺陷；不触发 HALT）

1. 首个 H 周期 n_fresh 取离散值 {68,534,272; 74,694,656; 80,855,040; 92,405,760}，相邻差恰为一个引擎步记录量 6,160,384，由 boot/warmup 时序决定；12 次新运行抽到 3 种值。
2. **同 draw → 轨迹字节一致**（4 对可核验：W1 A_v1 b1≡b2、W1 F_dense b1≡b2、W2 A_rev1 b1≡b2、W1 A_rev1 b1 与 W1 A_v1 的 TRACK 期信号一致）；**异 draw → 轨迹分叉**（W1 A_rev1 b1≠b2；W2 A_v1 b1≠b2：171行/34转换 vs 198行/20转换；封存 W2 A b1≠b2：164/33 vs 171/34；封存 F_dense b1/b2 draw 亦不同）。v1 与 rev1 臂同等敏感——非 rev1 引入。
3. 分叉机制完全定位于首个 QUIET 进入之前的 TRACK 期信号：W1 A_rev1 b2 的 h6–h8 h_rate（0.009905/0.010024/0.009948）连续 <θ_in → h8 进入；b1 的 h7=0.010447>θ_in → streak 重置 → h26 进入（与 A_v1 同）。
4. 排除代码原因：git diff f11bd01..HEAD 仅 rev1 三文件；rev0 重放 proposal_hash 位一致（4 份封存 A 日志 100% 匹配）；F_dense 决策账本跨战役一致（行数/交换/记录/p2l 全同，仅信号尾数随 draw 微移）。
5. 跨战役"臂间数值交换"假象 = draw 匹配的巧合：z/h_rate 序列 = f(boot draw, 决策)。
6. 推论（如实）：(i) 封存 P1 数值不能作新战役数值基线——协议内 A_v1 臂即为此设，本报告全部对比均为战役内配对；(ii) A_rev1 n=2 的 W1 两 block 为两个信号实现，方向性对比强度削弱；(iii) 任何自适应臂的重复间"字节一致"只在同 draw 下成立，论文口径不得声称跨 boot 决定性。
