## 2. 两级结构：探测许可 ≠ 正式扩窗准入（指令①）

### 2.1 探测许可（一次性，W16→W32→W16 的 ABA 结构）

**触发条件**（全部满足，在窗边界以 rank 一致输入求值）：
- (T-a) ramp 排除：启动以来已提交 ≥ R 窗（R 预注册；封存战役：W1 交换集中于 w1–w2，ramp 漂移在前四分之一）；
- (T-b) 潜在收益可测：c_b 样本 ≥ K 窗，且节省率 c_b×(1/16−1/32) 的**经验区间**（无覆盖证明，仅作预算准入门槛，不作提交证据）排除零；
- (T-c) 无活动域事件：无待确认收缩、无告警、desync 干净；
- (T-d) 本 run 许可未消耗。
未触发 → run 保持 W16 结束，无义务探测。

**段结构**（长度在触发时刻冻结，先于任何候选段数据——这是 §3.4 覆盖论证的锚点）：

| 段 | W | 预算 | 作用 |
|---|---|---|---|
| 参考段 | 16 | N_ref 窗 × 16 步 | 基线速率 + 漂移前锚点 |
| 候选段 | 32 | N_cand 窗 × 32 步 | 处理段；切换（16→32）落在其前沿**段内** |
| 回退段 | 16 | N_fb 窗 × 16 步 | 漂移后锚点 + 可逆性核查；切换（32→16）落在其前沿段内 |

探测 forward 总预算 P = 16(N_ref+N_fb) + 32·N_cand ≤ P_max（预注册）。两次切换成本被段包含、只计一次、不另立分项（§2.3-DC4）。

**风险上限**（ε_risk：预声明绝对 ms，作者设定的可接受损失预算，**不是模型分位数**）：
- 候选段每窗边界在线监控：excess_cum = Σ候选步数 × max(0, 运行中候选速率 − 参考速率)。监控不做漂移校正（回退段数据尚不存在）→ 可能假中止，方向保守（假中止 → UNKNOWN → 保持 W16）。
- excess_cum > ε_risk → 当窗边界立即中止 → 进入回退段。
- 监控粒度 = 窗边界（W32 ≈ 32 步 ≈ 11s 量级）；不引入窗中新增集合通信。预注册设 ε_risk_total = ε_risk + 单窗最坏过冲余量。

**停止条件**（穷尽）：
- (S1) 段预算耗尽 → 正常评估（§3.3）；
- (S2) 风险上限触发 → 中止 → 回退；
- (S3) 探测期间既有检测器确认域事件（收缩/告警）→ 中止，**既有收缩路径接管**（非探测回退路径），探测结果 = UNKNOWN-污染；
- (S4) 一致性/desync 告警 → 中止，探测无效，既有 run 有效性规则原样适用。

**一次性条款**：许可每 run 恰一次；UNKNOWN 或 NEGATIVE → 本 run 余下保持 W16；**无重探、无延长段、无换参数再试、无重分析直至出现正结果**。任何探测变体 = 新 run + 新预注册。

### 2.2 正式扩窗准入（一次性，回退段末评估）

提交 W32 于本 run 余下部分，当且仅当：Δ_net（§3）有利方向、其区间按 §3.4 具"条件置信"标签且排除零、三段均无布局混杂旗标、无 S2–S4 中止。否则保持 W16。
- 无需 horizon 计算：Δ_net 为每步速率量，有利速率在任意剩余流上逐步骤积（流位置是可观察历史，不需未来信息）。
- 提交后既有检测/收缩仍可在域变时收缩——安全网不变。
- **规则只用 Δ_net 一个量**；v0 的分项置信界相加规则已撤回（§4）。

### 2.3 决策量纪律：单位、混杂、重复计费（指令②）

- 唯一决策量：**Δ_net（ms/step，真实 forward 计数分母）**。
- 一切分项（c_b 分解、h_rate、λ 模型、切换成本）= 诊断/研究用途，**禁止与 Δ_net 加减进入任何不等式**——它们要么已含在 Δ_net 内，要么在线不可识别（明确 UNKNOWN）。
- 重复计费禁令台账：
  - DC1：边界节省已在 Δ_net 内（段墙钟含边界跨度）→ 永不再加 B；
  - DC2：研究模型 rate_gap 与 Δ_net 同源 → 永不并入同一不等式；
  - DC3：c_b 分项在 coverage<1 时与推理重叠 → 诊断使用须乘非重叠比例；
  - DC4：切换转移成本在段内计一次，不另列。
- 单位注册表（预注册附件）：ms/step（Δ_net、各段速率）；ms/边界（c_b）；步（预算、延迟）；ms（ε_risk）。合法换算仅经实测量：ms/step ↔ ms/run 经真实 forward 计数；ms/边界 ↔ ms/step 经实测步/边界；跨 rank 聚合 = max（暴露/偏斜）或逐 rank 报告，**禁止求和**。
- 量化问题设计消除：legacy 秒粒度窗戳（W16 下 ±17% 量化）由单调 ms 戳替代；段速率 = 段墙钟跨度 ÷ 段真实 forward 数（聚合量，非逐窗 s/step 平均）。
- 前后速率混杂的处理 = §3 的 ABA 漂移校正 + 混杂旗标，而非事后分项修正。

## 3. 净效果估计量（可观察优先）（指令②）

### 3.1 定义
rate_seg = 段单调钟跨度 / 段真实 forward 计数（ms/step）；三段：pre（参考）、cand（候选）、post（回退）。

### 3.2 漂移校正净效果（ABA 差中差）
- g = (rate_post − rate_pre) / 两段中点间步数（线性漂移率）
- **Δ_net = rate_cand − [ rate_pre + g × (pre 中点→cand 中点步数) ]**；Δ_net < 0 = 候选更快（有利）。
- Δ_net 内含段中发生的一切：边界暴露变化、陈旧效应、切换瞬态——**无需加成分项**。
- 假设（显式，预注册固化）：A1 漂移在探测跨度内近线性；A2 探测内无域事件（S3 强制，残余风险→UNKNOWN 标签）；A3 流切片异质性相对段长缓变——**内建空检验**：rate_post vs rate_pre 同为 W16，其差 = 漂移+切片噪声的噪声底，M3 实测；A4 段内布局稳定或被旗标（§5.2）。

### 3.3 结果三分类
- POSITIVE：Δ_net 有利、区间（§3.4 标签）排除零、无旗标、无中止；
- NEGATIVE：Δ_net 不利且区间排除零（不利侧）、无旗标；
- UNKNOWN：区间跨零 / 任何中止（S2–S4）/ 样本不足 / 布局混杂旗标（默认；预注册可定义条件化分析，缺省 = UNKNOWN）。

### 3.4 区间诚实性（指令③命名纪律）
- **完成探测、无提前停止**：段长在触发时刻先于候选数据冻结 → 步级速率的两样本/置换区间在 A1–A4 下有条件覆盖论证 → 标签"**条件置信（A1–A4）**"。
- **中止/数据依赖停止**：停止规则看了运行统计量 → 选择性停止使朴素区间失效 → 标签"**经验区间（无覆盖保证）**"，结果至多 UNKNOWN 或指示性，**永不作提交依据**。
- v1 任何区间不得称"严格置信保证"，除非预注册文档给出所用自适应程序的覆盖论证。

## 5. 与既有机制的接口（指令④）

### 5.1 保留清单
检测/确认/收缩/告警/dwell/cap/一致性/remap 版本文本不变。探测复用既有确定性 W 变更提交机制（封存战役已证 rank 一致提交可行）；回退走同一提交路径，事件类型 `probe_fallback`（≠ `confirmed_shrink`，审计分离）。dwell 交互：probe_fallback 由许可驱动、豁免 dwell 入场限制，但提交/回退后按既有语义重新武装 dwell 对后续扩张的约束——精确语义列为预注册开放项。

### 5.2 探测期间布局是否继续演化
**继续——规划/重规划规则在探测期间原样运行**（最小修改原则：冻结布局将是第二处行为变更，且改变被估对象）。混杂处理：布局指纹（决策级日志 d4）每窗末记录；参考/候选/回退任一段内发生 swap 提交 → 该段旗标 `layout_confounded` → 缺省结果 UNKNOWN。经验预期（封存战役）：W1 交换集中 w1–w2（在 T-a 之前）→ W1 污染概率低；W2 存在中段重规划（如 M 臂 w22）→ W2 污染可能，M3 实测旗标率。

### 5.3 回退不能恢复的状态（明示清单）
- F1 已耗墙钟与 forward——永久计入主终点（不删除、不扣除）；
- F2 探测许可——任何探测尝试（含中止）即消耗；
- F3 布局状态——探测期间已提交的 swap **不回滚**（回滚 = 未被计量的干预）；从当前状态继续演化；
- F4 流位置——探测期间消费的请求不可回卷（真实流）；
- F5 版本号——p2l/remap 版本单调，不回退；
- F6 检测器记忆——z/streak/dwell 计数按既有语义延续，探测不重置。
回退只恢复两样：W=16 节奏（经提交路径）与准入闸门状态（本 run 关闭）。

### 5.4 各 rank 如何共同提交
- 探测状态机（ARMED → TRIGGERED → EVAL → COMMITTED | FALLEN_BACK | ABORTED）是既有边界 gather 后 rank 一致输入的**确定性函数** → 各 rank 在同一边界独立求值得到相同状态；**不引入新集合通信**，决策搭载既有边界同步。
- 中止监控取 excess 的跨 rank **max**（绝不求和）→ 所有 rank 看到同一触发值。
- 每 rank 窗行追加 `probe_state`、段 id、excess_cum、许可位；既有 desync/一致性检查扩展覆盖这些字段；跨 rank 不一致 → 按既有无效 run 规则处理（不变）。
- 中止/评估粒度 = 窗边界（§2.1）；ε_risk_total 含单窗过冲余量。
