## 2. 两级结构

### 2.1 探测许可（至多一次）
- 每 run **至多一次**探测事件（W16→W32→W16 ABA）；触发条件（T-a ramp 排除 ≥R 窗；T-b 潜在收益可测——校准期以确定性触发替代并标注偏离；T-c 无活动域事件；T-d 许可未耗）全程不满足 → **零次探测，run 以 W16 结束，合法结果**。
- 段长（N_ref/N_cand/N_fb 窗）在触发时刻冻结；风险上限 ε_risk 为**中止阈值**：候选段每窗末检查累计超额 excess_cum（由 rank 归约后的计时序列计算，跨 rank 一致），excess_cum > ε_risk → 下一窗回退，事件 `probe_abort_risk`，**过冲 =（excess_cum − ε_risk）与单窗粒度滞后一并记录**；不宣称总损失被硬性约束在任何界内。
- 停止条件（穷尽，同 v1）：S1 预算尽；S2 ε_risk 中止；S3 检测器确认域事件（收缩族/冻结族）→ 探测 = UNKNOWN-污染，既有收缩路径接管 W；S4 desync → 既有 run 有效性规则。
- **无重试**：许可一次性；UNKNOWN/NEGATIVE → 本 run 余下 W16；不重探、不延长、不重分析直至正结果。

### 2.2 正式准入（校准期禁用）
- 提交 W32 仅当 EVAL 分类 = POSITIVE 且 `OEPLB_PROBE_COMMIT=1`；**M1–M3 全程 COMMIT=0（两臂均不永久准入）**——EVAL 照常计算并记录，W 保持 16。
- 提交决策延迟一窗（EVAL 在回退段末窗相 4 计算，提交提案在下一窗边界进入联合提交）——生产语义，校准不触发。
- **跨 rank 聚合与共同提交（指令 3）**：逐窗计时摘要（span_us、bcost_us、steps、true_steps_total）随既有 confirm MIN/MAX 集合通信归约（固定顺序、无条件、每窗一对，负载从 2 元素扩为 6 元素 int64）；决策序列取 **MAX**（最慢 rank 支配服务，绝不求和）；steps 以 MIN==MAX 验证 lockstep；探测状态机是归约后序列的确定性函数 → 各 rank 同边界得出同状态；W 变更（probe_start/fallback/abort/gated/commit）全部经既有 decision-hash 联合提交路径（override 在 hash 之前、各 rank 相同）；`probe_state` 入每 rank 窗行并纳入 desync 审计。

## 3. ABA 净效果估计（指令 2 修订后）

- rate_seg = Σspan_max / Σ真实 forward 步（µs/step，段聚合，ms 级单调钟——量化问题设计消除）。
- g = (rate_fb − rate_ref)/(中点步距)；**Δ_net = rate_cand − (rate_ref + g×(pre→cand 中点步距))**。
- **定位声明（随每次报告强制引用）**：Δ_net 是经背景趋势差分校正的**观察性估计**；残留假设 A1（漂移近线性）A2（探测内无域事件）A3（流切片异质性缓变）A4（段内布局稳定或被旗标）不被本设计消除；**不宣称已隔离因果**。
- **区间纪律（撤回自动条件置信）**：校准期只报告点值与跨 block 描述性分布；任何区间 = "经验区间（无覆盖保证）"；覆盖论证栏 = **留空**（尚不能支持）。完成探测不再自动获得任何置信标签。
- 分类（校准临时规则，仅用于 AAA 误判测量）：ε_prac = 1% × rate_ref；Δ_net ≤ −ε_prac → favorable；≥ +ε_prac → unfavorable；其间或任何中止/污染/布局混杂/anomaly → UNKNOWN。生产阈值与正式统计方法 = 留空。
- 保留纪律：所有中止（S2/S3/S4）、污染、anomaly（hold 窗）事件**保留**于 jsonl 与报告；不删除、不静默排除。

## 5. M1→M2→M3（指令 4/5，数值与顺序见 PRE_REG，冻结）

- **M1（4 启动，mode=off）**：仪表化代码在既有 v2.1 行为上的自成本与**行为不变性**验证——窗/事件/W/提交序列必须与封存 A 臂逐窗一致（机制门槛，阻塞 M2；端点值永不作门槛）。
- **M2（3 启动，mode=gate）**：机制验证——正常 ABA 路径、强制中止路径（FORCE_ABORT_AT=1 机制配置，标记隔离）、W2 域事件交互观察。许可恰至多一次、rank 一致（desync=0、h_min==h_max）、回退后 W=16、状态审计一致（机制门槛，阻塞 M3）。
- **M3（8 启动 = 4 个 AAA/ABA 配对 block，顺序冻结：b1 W1、b2 W1、b3 W2、b4 W2；block 内 AAA 先、ABA 后）**：AAA = mode aaa（全程 W16，相同触发点与段预算打标，增长同样被闸），ABA = mode gate；两臂 COMMIT=0。产出：AAA 误判表现（Δ_net 对 ε_prac 的分类 = 估计器空分布）、ABA 估计稳定性（跨 block 分布 + 段内结构）、污染/中止率、完整服务差（同 block ABA−AAA total_time_s）、新增成本（账目）。**仅开发校准数据**：不回填封存结论、不预挑正式战役参数、不作部署收益宣称。

## 6. 交付与成功标准（指令 6）

交付物：15 次启动逐次结果（verdict/total_time_s/关键账目）、AAA 误判表、ABA Δ_net 稳定性表、污染/中止/anomaly 率、完整服务差、日志自成本账目（对 ε_log 门槛）、机制门槛核验记录、全部保留的中止/污染事件清单。
**成功标准 = 测量可信（M1 账目+行为不变）、机制正确（M2 全路径）、估计器可接受检验（M3 空分布+稳定性可算）**。不以是否出现正收益判定成功。若结果表明净效果无法可靠辨识（如 AAA 空分布覆盖 ε_prac、或污染率过高），**如实报告该限制**，不反复调到通过。正式部署收益另行评价（不在本轮）。
