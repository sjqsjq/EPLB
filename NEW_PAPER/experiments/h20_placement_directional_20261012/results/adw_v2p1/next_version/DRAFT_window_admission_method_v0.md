## 0. 范围与不变承诺

- **唯一变更点：扩窗准入闸门**。现有检测（z、θ、确认窗、收缩、告警）与一致性修正、dwell/cap 机制全部保留不动（作者指令⑤）。
- 沿用的常设纪律：真实请求；无延迟 floor/无干预；迁移/setup/JIT/warmup 在计时块外；8 rank 并行——**任何时间量不得跨 rank 求和**；不扣除任何实测成本（新日志成本计入端点，只受 §5-T5 的 ε 约束）。
- 两条硬禁令（作者指令③）：
  (i) 影子规划的 Δ目标函数**不得**直接当作时间收益进入任何准入量；
  (ii) 控制器**不得**使用未来真实域边界/域切换信息——所有在线估计只用本 run 已发生的历史（或版本冻结的离线先验，见 §5.5）。
- 影子规划器**暂不作为必选实现**（作者指令④）。

## 2. 准入规则（作者指令②）

在边界决策点，仅用历史信息，扩窗 W→W′ 当且仅当：

> **LCB( B ) > UCB( C1 ) + UCB( C2 ) + UCB( C3 )**

- B = 预计节省的边界暴露成本率（ms/step）
- C1 = 预计新增执行损失率——新鲜度分量（ms/step）
- C2 = 预计新增执行损失——检测延迟分量（ms/step 期望）
- C3 = 额外决策成本 + dwell 锁定成本（ms/step 折算）
- LCB/UCB = 预先声明置信水平的区间界（数值在预注册时定）

任一项**样本不足或区间重叠 → UNKNOWN → HOLD**（本边界不扩，下一边界重评）。不插补、不乐观缺省。
**稳定与低 h_rate 只能进入损失侧（C2 的 hazard 项），不构成收益证据，永不单独授权扩窗。**
收缩侧规则不变；扩张仍受 W_max 与 dwell 约束。

## 3. 各量：单位 / 可观察信号 / 估计方法 / 误差与假设 / 在线可得性（作者指令③）

### B — 边界暴露节省（收益侧）

| 项 | 内容 |
|---|---|
| 定义与单位 | c_b = 每个窗边界上**未被推理重叠的关键路径暴露时间**（ms/边界）；收益率 B = c_b × (1/W − 1/W′)（ms/step，速率形式，**不需要知道剩余步数**，避免引入未来信息） |
| 可观察信号 | §4c 分项时间戳（stats-gather / allreduce 等待 / plan-build / remap-check / controller-total）+ 边界墙钟跨度（上窗末步结束→下窗首步开始）+ coverage 字段 |
| 估计方法 | 最近 K 个边界的 c_b 稳健均值（rank0 关键路径口径；涉及集合通信等待时取跨 rank 的 max，**绝不求和**）；只计 (1−重叠) 部分，重叠由 coverage 检出 |
| 误差 | 单调钟抖动 ~µs 级；K 个边界的样本方差；coverage 缺口导致 c_b 高估暴露（保守方向，利于不扩）；**假设 c_b 对 W 弱依赖**（stats 缓冲随 W 增大可能变大——列为待检验假设，分项日志可直接核验） |
| 假设 | 边界各段位于关键路径（由 coverage 验证，即 T1 可证伪点） |
| 在线可得 | **是**：CPU 时间戳挂在既有阻塞点上，无新增 GPU 同步 |

### C1 — 执行损失：新鲜度分量

| 项 | 内容 |
|---|---|
| 定义与单位 | 更大 W 使布局/统计更陈旧造成的每步服务时间增量（ms/step） |
| 可观察信号 | 每步服务率（§4a 单调钟 + §4b 真实 forward 计数）按 W 段分层；窗末 h_rate 轨迹（已知局限：仅窗末对当前布局快照，只作辅助）；布局指纹（§4d）用于条件化"布局是否变过" |
| 估计方法 | run 内既往扩张事件的前后速率差（限定在无确认域事件的段内），跨事件合并出 CI；**既往事件数 < n_min → UNKNOWN → HOLD**（n_min 预注册时定） |
| 误差 | 与 ramp/域漂移混杂（封存战役已证明 ramp 与扩张时序纠缠）；每 run 扩张事件少（≤2）→ CI 宽；段长不等 |
| 假设 | 对比段内准平稳；扩张效应与布局交换效应可分离（指纹条件化） |
| 在线可得 | **是**（边界处由已记录历史计算，纯 CPU）；但受最小样本门控——由此产生 §5.5 引导问题 |

### C2 — 执行损失：检测延迟分量

| 项 | 内容 |
|---|---|
| 定义与单位 | 扩窗使确认收缩/域变的延迟最多增加 (W′−W) 步，延迟期间以错配节奏运行的期望增量成本（ms/step 期望） |
| 可观察信号 | z 轨迹；既往确认收缩事件及其滞后（窗/步）；C1 的速率差上界 |
| 估计方法 | hazard λ = 既往域事件率（事件/步，**仅本 run 历史或冻结先验**）；期望延迟 ≈ (W′−W)/2 步/事件（最坏 (W′−W)）；C2 = λ_UCB × 延迟 × 速率差 UCB |
| 误差 | λ 由小计数估计（W2 型 run 仅 1 事件）→ 用上置信限而非点估计；速率差上界本身宽 |
| 假设 | 既往 hazard ≈ 近未来 hazard——**对单边界域（正是 W2）此假设弱**，为已知短板，保守 UCB 只部分覆盖；不引入未来域信息是硬约束，接受此代价 |
| 在线可得 | **是**（仅历史） |

### C3 — 额外决策成本 + 锁定成本

| 项 | 内容 |
|---|---|
| 定义与单位 | 准入计算自身耗时（ms/边界，实测报告）；锁定成本 = 误扩后被 dwell 锁在更大 W 的最坏增量（ms，折算 ms/step） |
| 可观察信号 | 准入求值墙钟；dwell 配置（步，已知常量）；C1 速率差 CI |
| 估计方法 | C3 = dwell_steps × UCB(速率差 W vs W′) / 折算步数；最坏情形界（扩张后立即需要小 W 且 dwell 全程持有） |
| 误差 | 最坏界系统性高估典型成本——**有意保守**，方向与准入闸门一致 |
| 假设 | dwell/收缩路径不变（§0 承诺） |
| 在线可得 | **是** |

### U — UNKNOWN/HOLD 门控

任何必需量缺最小样本、或区间重叠 → UNKNOWN → HOLD。HOLD 事件本身入日志（可审计"闸门何时因何拒绝"）。

### 5.5 引导问题（bootstrap，**留给作者决策，本草案不预定**）

C1 的在线估计需要 run 内既往扩张事件，而准入闸门又拦截无证据的扩张——首个扩张存在鸡生蛋问题。三个候选：

- **A. 冻结离线先验**：C1 先验来自封存战役工件 + 未来标定 run 的离线分析，版本冻结后供在线使用（属历史信息，不违反禁令 (ii)）。缺点：封存战役已证明跨臂布局不同且 W 段对比有混杂，先验 CI 会很宽。
- **B. 有界探测**：每 run 至多一次"探测性"扩至 W=32，条件 = LCB(B)>0 且 (C2+C3) UCB（C1 用离线先验 UCB）低于 LCB(B)；扩至 64 必须有 run 内实测 C1。保留自适应性的同时把无证据扩张限为一次、限幅一级。
- **C. 不引导**：首扩永不在线获准 → 方法退化为"固定 W=16 + 仅收缩自适应"。若作者认为先验证据不足以建立正净价值，这是与指令②最一致的缺省。
