# 严密的 Adaptive Window / Adaptive Decay 设计

## 1. 问题诊断:当前设计为什么不够严密

当前实现(controller.py §3.5)有三个未经论证的地方:

| 参数 | 当前值 | 依据 | 问题 |
|---|---|---|---|
| 收敛阈值 | Δr<0.003 连续3窗 | 无 | 拍的 |
| 切换阈值 | Δr>0.03 | 无 | 拍的 |
| 确认窗数 | 3 | 无 | 拍的 |
| decay α | 0.5 | A.2 单点数值解(SNR=3,γ=1) | γ、SNR 无来源 |
| 窗口/decay关系 | 分开设计 | — | 二者数学耦合却各调各的 |

## 2. 核心理论:W 和 α 不独立,真正的自由度是有效记忆 M

指数衰减累加器 A_t = R_t + α·A_{t-1},每 W 个 forward 决策一次。稳态下:
- **有效样本量** N_eff = W/(1-α) × (每forward的token数)  —— 决定方差(抽样偏差 ∝ 1/√N_eff)
- **有效记忆时间** M = W/(1-α) (以forward计)  —— 决定对变点的响应延迟

关键洞察:**W 和 α 只通过 M=W/(1-α) 影响稳态行为**。固定 M,增大 W 同时增大 α 得到相同的偏差-方差权衡,但 W 大→决策频率低→all_reduce 开销低。所以:
- **α 控制"遗忘曲线形状"**(几何衰减 vs 硬窗口),
- **W 控制"决策频率/开销"**,
- **M=W/(1-α) 控制"偏差-方差工作点"**,是唯一真正需要按负载调的量。

当前设计的 bug:调 W 时没同步调 α,等于在无意中移动了 M。

## 3. M 的最优值:偏差-方差 + 变点检测的联合最小化

### 3.1 两个代价
- **方差代价**(小 M):抽样偏差 bias(M) = c/√(M·t̄),其中 t̄=每forward每层token数,c=0.65·EP(附录D.2标定)。
  该偏差导致 η 损失,当 bias > γ(r-r_k) 时决策不可信(§3.5的 sw_min)。
- **延迟代价**(大 M):变点后需 ~M·ln2 步旧信号才衰减到半(几何衰减),
  这段时间用错误布局服务,损失 ≈ β(r_new - r_k)·(M ln2/总步数)。

### 3.2 联合最优
设段长 L_seg(两次域切换间的平均forward数,可在线用变点检测估计),则
  总损失(M) = 方差损失 + 延迟损失/L_seg × (切换频率)
最优 M* 满足 d/dM = 0:
  M* = argmin_M [ a·c²/(M·t̄·γ²(r-rk)²)  +  b·β(r-rk)·M·ln2/L_seg ]
一阶条件给出闭式:
  **M* = sqrt( a·c²·L_seg / (b·β·t̄·γ²·(r-rk)³·ln2) )**
即最优记忆随段长 √L_seg 增长、随信噪比(r-rk)^1.5 下降。这是一个**可计算**的量,
所有参数都能在线测:c=0.65EP(已知)、t̄(录制)、r、rk(幂律)、β(profiling)、L_seg(变点检测)。

### 3.3 从 M* 反推 W 和 α
给定 M* 和一个开销预算(每 W 步一次 all_reduce,预算 = 可接受的通信占比 ρ):
  W = max(W_min, ρ·L_seg)      # 开销约束决定 W 下限
  α = 1 - W/M*                  # 由 M* 和 W 反解
若 W/M* ≥ 1(即 M* < W),说明段太短、需要比一个窗口还短的记忆 → 退化为 α=0(纯窗口,不累积)。

## 4. Adaptive Decay(当前完全没有,只有固定0.5)

变点检测应该同时调 α,不只调 W:
- **稳态**(cos_sim 高):增大 M(增大 α 或 W)→ 低方差
- **检测到变点**:α 瞬时归零一次(丢弃旧域历史,= 当前的 load.zero_()),然后从小 M 重新增长
这比当前"只缩 W、α 恒 0.5"更快:α=0.5 意味着变点后旧信号残留 50%,需 1 步才半衰;
若变点时 α→0,旧信号立即清空,响应延迟从 M ln2 降到 0。

## 5. 需要的 235B 实验(driver29)

现有数据不足以标定:多域日志只有4个cos_sim点,且driver22的"多域"数据集实测是同质的
(σ/μ=0.93 但 r_before 各数据集差<1.5%)。必须构造**真正的分段平稳负载**并扫 (W,α)。

### 实验设计
1. **构造分段负载**:把 L256(数学) / ShareGPT(对话) / 多域 三个数据集的请求
   按已知段长 L_seg ∈ {50, 200, 1000} 交替拼接,形成受控的变点序列。
2. **网格扫描** (W, α):
   W ∈ {8, 16, 32, 64, 128},α ∈ {0, 0.3, 0.5, 0.7, 0.9}
   在 235B/EP8 上,每点测吞吐 + 记录 cos_sim 轨迹 + 决策次数 + swap 代价。
3. **验证 M=W/(1-α) 是充分统计量**:画吞吐 vs M 的散点,看不同 (W,α) 但相同 M 的点
   是否落在同一条曲线上(若是→证明 M 是正确的抽象)。
4. **验证 M* 闭式预测**:用第3.2节公式算每个 L_seg 的 M*,看是否命中扫描的峰值。
5. **对比 adaptive vs 最优静态**:自适应策略应逼近"每段用该段最优 M"的 oracle。

### 预注册预测(实验前写下)
- P1: 吞吐主要由 M=W/(1-α) 决定,同 M 不同(W,α)的吞吐差 < 2%(证明 M 是充分统计量)
- P2: 最优 M* 随 L_seg 单调增(√关系)
- P3: adaptive decay(变点时α→0)比固定α=0.5在短段(L_seg=50)上快 ≥ 1 个决策窗口收敛
- P4: 235B 的最优静态 M 在稳态负载上 ≈ 现有 sync_window=16 附近(验证默认没错得离谱)
