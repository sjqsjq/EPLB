# 顺序表（锁定，seed=20261027，先于任何GPU消耗生成）

规则：第1-3轮 = 随机基础顺序的循环移位(0,1,2)；第4轮 = 事先固定排列 = 基础顺序反转。
基础顺序: ES I P1 DF ED P0 MT

- 第1轮: ES -> I -> P1 -> DF -> ED -> P0 -> MT
- 第2轮: I -> P1 -> DF -> ED -> P0 -> MT -> ES
- 第3轮: P1 -> DF -> ED -> P0 -> MT -> ES -> I
- 第4轮: MT -> P0 -> ED -> DF -> P1 -> I -> ES

首轮位置: ES I P1 MT（无臂四轮皆首，AERO非恒首）
